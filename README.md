# Ayu Personal: experimental public build

Unofficial experimental iOS Telegram fork. The patch applies to the pinned
[Telegram iOS](https://github.com/TelegramMessenger/Telegram-iOS) revision and
includes selected changes derived from [Madgram iOS](https://github.com/yar2slav/Madgram-iOS).
The bundle identifier includes the GitHub username `addmemud`.

The workflow uses Telegram Desktop's public TEST ONLY API credentials and
produces an unsigned iPhone archive. Compilation does not verify installation,
login, privacy, media retention or the UI. A separate personal signature is
needed before installation. Do not add private credentials to this public repo.
